# Хакатон ТОП-ИИ 2026
## Кейс 3 Альтернативный Скоринг (Telegram-аналитика) (Сбер)
*Проблема:*
Студентам, самозанятым и фрилансерам без официальной кредитной истории банки отказывают в займах, хотя они могут быть платежеспособными.

*Решение:*
Пользователь загружает выписку с карты за 3 месяца. Сервис рассчитывает простые метрики: средний остаток, регулярность поступлений, долю трат на необходимые товары - и выводит «оценку благонадежности» (от 0 до 100).

*Как сейчас:*
Банки используют только официальные доходы и бюро кредитных историй - для нестандартных заемщиков это тупик.

*Al-фича:*
С согласия пользователя парсится его публичный Telegram-канал (или чаты). Модель (LLM + NER) анализирует лексику, частоту упоминания работы, подписки на финансовые каналы - строит психологический портрет и корректирует скоринг с объяснением («Вы часто пишете о проектах, значит, занятость стабильна - +10 баллов»).
